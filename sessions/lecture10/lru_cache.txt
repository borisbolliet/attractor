Lecture 10, memoisation of the Fibonacci recursion with lru_cache. Run from the project root:
    python -m doctest -v sessions/lecture10/lru_cache.txt

>>> import functools
>>> @functools.lru_cache(maxsize=None)
... def fib(n):
...     return n if n < 2 else fib(n - 1) + fib(n - 2)
...
>>> fib(80)
23416728348467685
>>> fib.cache_info()
CacheInfo(hits=78, misses=81, maxsize=None, currsize=81)
