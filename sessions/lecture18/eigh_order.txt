Lecture 18, the order of eigh: eigenvalues ascending, the eigenvector of w[i] in column i, and the k leading eigenvectors by reversing the columns.
    python -m doctest -v sessions/lecture18/eigh_order.txt

>>> import numpy as np
>>> C = np.array([[2.0, 1.0, 0.0], [1.0, 2.0, 0.0], [0.0, 0.0, 5.0]])
>>> w, U = np.linalg.eigh(C)
>>> w.round(12)
array([1., 3., 5.])
>>> np.abs(U[:, -1]).round(12)
array([0., 0., 1.])
>>> bool(np.allclose(C @ U, U * w))
True
>>> w[::-1][:2].round(12)
array([5., 3.])
>>> np.abs(U[:, ::-1][:, :2]).round(4)
array([[0.    , 0.7071],
       [0.    , 0.7071],
       [1.    , 0.    ]])
